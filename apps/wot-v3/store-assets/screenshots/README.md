## How they are taken

`e2e/store-screenshots.spec.ts` runs the harness page with two phones (Jonas Weber, Noah Lindqvist; fictional) over a live TSP 1.0 mediator: Noah shows his code, Jonas scans it once, Noah confirms, then four messages go back and forth. Each phone frame is set to 360×780 CSS pixels and shot at device scale factor 3. The onboarding screens come from the `fresh-install` scenario on the simulated device. Language `lang=de`, time zone `tz=Europe/Berlin`. The Magic Words are generated by the simulated device and belong to no one.

From `apps/wot-v3`:

```bash
RLTP_LIVE_MEDIATOR=1 \
MEDIATOR_DID="did:webvh:QmUTUkdHgppiciLpqcxkTi6Pbc9VuZzWXvH4L2Dk2dY2WL:mediator.web-of-trust.de" \
WOT_CHROME_PATH=/path/to/chromium-1208/chrome-linux64/chrome \
WOT_SHOTS_DIR=store-assets/screenshots \
pnpm exec playwright test -c playwright.screenshots.config.ts
```

The config builds the harness and serves it on port 5291 (`WOT_SHOTS_PORT` to change it). Without `RLTP_LIVE_MEDIATOR=1` the spec is skipped. The QR code and the times differ on every run.
